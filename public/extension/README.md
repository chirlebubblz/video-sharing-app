# DefinitelyNotLoom Floating Chrome Extension

This extension turns your Loom Clone into a full-featured browser recorder just like Loom!

## Features
- 🎥 **Floating Camera Bubble:** Appears on ANY website you visit (Vercel, GitHub, Google, PowerPoint, etc.).
- ✏️ **Live Pen Tool:** Draw and annotate directly on any webpage while recording.
- ⏱️ **Floating Control Dock:** Timer, Cam Toggle, Pen Toggle, and Stop & Upload button.
- 🚀 **Instant Upload:** Uploads recordings directly to your live Vercel cloud server (`video-sharing-app-jordan.vercel.app`) and opens your AI Video share page automatically!

---

## 3-Step Setup Instructions

1. Open **Google Chrome** or **Microsoft Edge**.
2. Navigate to: `chrome://extensions` (or `edge://extensions`).
3. Enable **Developer mode** (toggle in top-right corner).
4. Click **Load unpacked**.
5. Select the folder:  
   `e:\Antigrav projects\Loom Clone\chrome-extension`

---

## How to Use
1. Open any website (e.g., [vercel.com](https://vercel.com) or [github.com](https://github.com)).
2. Click the **DefinitelyNotLoom** extension icon in your browser toolbar.
3. Click **Start Floating Record**!
4. The camera bubble, drawing pen, and recording control dock will float directly on your active page!
